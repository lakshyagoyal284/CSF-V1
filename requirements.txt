# Alternative Credit Scoring Engine - Python dependencies

# Tested on Python 3.12 (Windows and Linux).
#
#   python -m venv .venv
#   .venv/Scripts/python -m pip install -r requirements.txt   # Windows
#   .venv/bin/python     -m pip install -r requirements.txt   # macOS / Linux
#
# NOTE on FastAPI/Starlette: ranges are used rather than exact pins because
# FastAPI and Starlette are version-coupled and a machine with an
# already-installed Starlette will otherwise end up with a mismatched pair
# (symptom: "Router.__init__() got an unexpected keyword argument 'on_startup'").
# A dedicated virtual environment avoids this entirely.
# Verified working combinations: fastapi 0.115.0 + starlette 0.38.6, and
# fastapi 0.143.3 + starlette 1.7.0.
# ---------------------------------------------------------------------------
